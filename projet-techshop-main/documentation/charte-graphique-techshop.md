# 🎨 Charte Graphique - TechShop

## 🎨 Palette de Couleurs

### Couleurs Principales
- **Bleu profond** : `#1E3A8A`
  - Usage : Couleur principale, header, footer
  
- **Cyan électrique** : `#06B6D4`
  - Usage : Accents, boutons CTA, liens

### Couleurs Secondaires
- **Gris ardoise** : `#334155`
  - Usage : Textes de contenu
  
- **Blanc cassé** : `#F8FAFC`
  - Usage : Fond de page, cartes produits

- **Orange vif** : `#F97316`
  - Usage : Promotions, badges urgence, alertes

---

## ✏️ Typographie

### Titres
- **Police** : Inter (Bold/ExtraBold) ou Poppins (SemiBold/Bold)
- **Usage** : H1, H2, H3, titres de sections

### Textes
- **Police** : Inter (Regular/Medium) ou Roboto (Regular)
- **Usage** : Paragraphes, descriptions, contenu général

### Prix & Chiffres
- **Police** : JetBrains Mono ou SF Mono
- **Usage** : Prix produits, quantités, numéros

---

## 📐 Espacements

- **Petit** : 8px
- **Moyen** : 16px
- **Grand** : 24px
- **Très grand** : 32px

---

## 🎯 Style des Composants

### Boutons
- **Principal** : Fond `#06B6D4`, texte blanc
- **Secondaire** : Fond `#1E3A8A`, texte blanc
- **Hover** : Légère opacité (0.9) + transition

### Cartes Produits
- Fond : `#F8FAFC`
- Bordure : Aucune ou `#334155` (1px)
- Border-radius : 8px
- Ombre : `box-shadow: 0 2px 8px rgba(0,0,0,0.1)`

### Badges Promo
- Fond : `#F97316`
- Texte : Blanc
- Border-radius : 4px
